# Data

Dataset not included in this repo due to file size and repo hygiene.

**Source:** [Genre Classification Dataset IMDb (Kaggle)](https://www.kaggle.com/datasets/hijest/genre-classification-dataset-imdb)

## Files expected in this folder
- `train_data.txt` — required. Format: `ID ::: TITLE ::: GENRE ::: DESCRIPTION`
- `test_data.txt` — optional (unlabeled test set)
- `test_data_solution.txt` — optional (true genres for the test set)

## How to get it
1. Go to the Kaggle link above and sign in (free account)
2. Click **Download** → extract the zip
3. Place `train_data.txt` (and the others, if you want them) directly in this `data/` folder
